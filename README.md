# Doughnut Economics: Global Social and Ecological Trends

## Overview
Analyzing social shortfall and ecological overshoot across countries and income groups (2000–2022), using tables and multi-panel visualizations.

## Tools
Python, pandas, NumPy, Matplotlib, Seaborn, Plotly

## Methods and outputs
Includes ecological and social indicator comparisons, trellis plots and a combined sandwich plot.

## Repository structure
- `analysis.ipynb`: original student analysis notebook
- `data/`: input data used by the notebook

## Run locally
1. Install Python 3.10+ and JupyterLab.
2. Install dependencies: `pip install -r requirements.txt`.
3. Open `analysis.ipynb` from this repository's root folder and run cells in order.

**Reproducibility note:** The notebook has been preserved from the submitted assignment, rather than rewritten or independently re-executed. Some charts may depend on notebook state, external files, package versions or interactive rendering. Validate the complete run before describing it as fully reproducible.
